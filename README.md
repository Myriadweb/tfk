# Teammate for Kids

## Prerequisites
Have node 16 (LTS) installed. Even better, install nvm and it will switch to the right node
version when you enter the folder.

## Install
`npm i`

## Current status/stack
The project was bootstrap with create react app with Typescript.
It has eslint and prettier installed and configured. They all run in a pre-commit hook to make sure
our files are linted, formatted and free of errors.

It has `i18next` and `react-pixi` installed.
